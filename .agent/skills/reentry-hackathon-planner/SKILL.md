# reentry-hackathon-planner

Read docs/TASKS.md and docs/STATUS.md. Compare actual current time against the stated freeze in docs/PROBLEM.md; do not assume a fresh 15-hour window. Mark work complete only with evidence. Do not hide missing core functionality with unlabeled fixture results.
