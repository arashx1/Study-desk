# reentry-frontend-wow

Read docs/PRD.md and docs/DESIGN_RESOURCES.md. Build for a narrow browser side panel with clear workspace, next step and actionable evidence. Open citations to saved passages, show source versions and distinguish suggested from approved changes. Handle empty/loading/offline/error/unsupported states and keyboard focus. Use a larger extension page only where the graph needs space. Verify layout at narrow widths. Do not add landing pages, excessive animation or unsupported claims about truth and trust.
