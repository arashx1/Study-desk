# ReEntry interface direction

Design a browser side panel, not a marketing page. Use clear workspace selection, a resume card, source list, claim impact list, evidence comparison and review controls. A larger evidence-map view can be an extension page.

Prefer quiet neutral surfaces, navy text, teal accent and legible typography. Show evidence state with words and icons, not color alone. Make capture and resume obvious at a narrow panel width. Support keyboard focus, readable citations, truncation with accessible full text, empty/loading/error/offline states and reduced motion.

Use existing project components before adding UI libraries. shadcn/ui, Aceternity UI, React Bits or v0 are optional references; check current licensing and compatibility before importing. Avoid decorative dependencies that threaten the core build. There are no verified subscriptions or installed design libraries in this setup.
